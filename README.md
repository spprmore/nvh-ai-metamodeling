# AI-Based NVH Metamodeling

This project demonstrates the use of machine learning as a surrogate model (metamodel) for predicting structural dynamic characteristics.

The objective is to reduce computational effort by replacing expensive simulation studies with fast, data-driven predictions. A dataset of virtual structures is generated, and machine learning models are trained to estimate natural frequencies from geometric and material parameters.

## Motivation
Modern CAE workflows often require large numbers of simulations. This project investigates whether machine learning can be used to create surrogate models that predict structural dynamic behavior and natural frequencies more efficiently, supporting future NVH and engineering analysis applications.

**Key Topics**
- Structural Dynamics
- NVH (Noise, Vibration, Harshness)
- Machine Learning
- Surrogate Modeling
- CAE Data Analytics
- Python

**Project Objectives**
- Generate a structural-dynamics dataset
- Predict natural frequencies using machine learning
- Compare actual and predicted responses
- Demonstrate AI-driven metamodeling for CAE applications
